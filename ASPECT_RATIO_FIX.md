# Aspect Ratio Fix

## Problem

The aspect ratio selected by users (1:1, 9:16, 16:9, 4:3, 3:2) was not being properly passed to the AI prompt generation, causing all generated images to default to 1:1 regardless of user selection.

## Root Cause

The aspect ratio was being passed to the Nano Banana API correctly, but it was NOT being passed to the Gemini prompt generation function (`mergePrompt`). This meant:

1. ✅ Nano Banana received the correct aspect ratio parameter
2. ❌ The JSON prompt generated by Gemini always had a generic placeholder
3. ❌ The AI didn't know what aspect ratio to design for

## The Flow

```
User selects aspect ratio (e.g., "16:9")
    ↓
generateAction(brandId, prompt, aspectRatio) ← aspect ratio passed
    ↓
mergePrompt(brandContext, prompt, ...) ← aspect ratio NOT passed ❌
    ↓
Gemini generates JSON with generic aspect_ratio
    ↓
callReplicate(json, aspectRatio, ...) ← aspect ratio passed
    ↓
Nano Banana receives aspect ratio but JSON prompt doesn't match
```

## The Fix

### 1. Updated `mergePrompt` Function Signature

**Before:**
```typescript
export async function mergePrompt(
  brandContext: any,
  userPrompt: string,
  referenceContext: any | null = null,
  imageInputs: {...},
  creativeMode: boolean = false,
  referenceInfluence: "low" | "medium" | "high" = "medium",
): Promise<NanobannaPrompt>
```

**After:**
```typescript
export async function mergePrompt(
  brandContext: any,
  userPrompt: string,
  referenceContext: any | null = null,
  imageInputs: {...},
  creativeMode: boolean = false,
  referenceInfluence: "low" | "medium" | "high" = "medium",
  aspectRatio: string = "4:3",  // NEW PARAMETER
): Promise<NanobannaPrompt>
```

### 2. Added Aspect Ratio to Context

**Before:**
```typescript
Brand Context: ${JSON.stringify(brandContext)}
Reference Images Context: ${referenceContext ? JSON.stringify(referenceContext) : "none"}
User Request: ${userPrompt}
```

**After:**
```typescript
Aspect Ratio: ${aspectRatio}  // NEW
Brand Context: ${JSON.stringify(brandContext)}
Reference Images Context: ${referenceContext ? JSON.stringify(referenceContext) : "none"}
User Request: ${userPrompt}
```

### 3. Updated JSON Output Template

**Before:**
```json
{
  "generation_settings": {
    "aspect_ratio": "string like 1:1 | 4:3 | 9:16",
    ...
  }
}
```

**After:**
```json
{
  "generation_settings": {
    "aspect_ratio": "${aspectRatio}",  // MUST match the requested aspect ratio exactly
    ...
  }
}
```

### 4. Updated All Function Calls

**generateAction:**
```typescript
fullPromptJson = await mergePrompt(
  brandContext,
  userPrompt,
  referenceContext,
  { logoUrl: brand.logo_url, referenceUrls: inspirationImageUrls },
  creativeMode,
  "medium",
  aspectRatio,  // NEW - Pass aspect ratio
);
```

**generateActionWithRefs:**
```typescript
fullPromptJson = await mergePrompt(
  brandContext,
  userPrompt,
  combinedReferenceContext,
  { logoUrl: brand.logo_url, characterUrl: characterBase64, referenceUrls: [...] },
  creativeMode,
  referenceInfluence,
  aspectRatio,  // NEW - Pass aspect ratio
);
```

## Why This Matters

### Design Composition
Different aspect ratios require different design approaches:

**1:1 (Square)**
- Centered composition
- Balanced layout
- Equal weight on all sides

**16:9 (Landscape)**
- Horizontal flow
- Wide hero images
- Side-by-side elements

**9:16 (Portrait/Story)**
- Vertical flow
- Stacked elements
- Top-to-bottom hierarchy

**4:3 (Standard)**
- Balanced composition
- Traditional layout
- Versatile design space

**3:2 (Photo)**
- Natural photo ratio
- Comfortable viewing
- Professional look

### AI Understanding
The AI needs to know the aspect ratio to:
- Plan element positioning correctly
- Calculate safe areas properly
- Design appropriate layouts
- Size text and images correctly
- Create balanced compositions
